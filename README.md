# Stock Advisor Discord Bot

บอท Discord สำหรับติดตามและคัดกรองหุ้นสหรัฐฯ รวมถึง ETF อิงตามข้อมูลปัจจัยพื้นฐาน ตัวชี้วัดทางเทคนิค และสภาวะตลาด โดยประมวลผลผ่านโมเดลคณิตศาสตร์ในเครื่องโดยตรง

---

## จุดเด่นการทำงาน

1. **ประมวลผลในเครื่อง:** คำนวณจากสูตรและข้อมูลงบการเงินจริงผ่าน Yahoo Finance ไม่ต้องพึ่งพา API ภายนอกที่เสียค่าใช้จ่าย
2. **โมเดลประเมิน 5 มิติ (คะแนนเต็ม 100):**
   - **ปัจจัยพื้นฐาน (30 คะแนน):** การเติบโตของรายได้ กำไรต่อหุ้น (EPS) และความสามารถในการทำกำไร
   - **มูลค่าราคา (20 คะแนน):** Dynamic PEG และ Forward P/E เทียบกับค่าเฉลี่ยของกลุ่มอุตสาหกรรม
   - **เทคนิคและโมเมนตัม (20 คะแนน):** แนวโน้มเส้น EMA (20/50/200), RSI (14), ปริมาณซื้อขาย (RVOL) และระยะห่างจาก EMA20
   - **สภาวะตลาดรวม (15 คะแนน):** ประเมินจาก S&P 500, Nasdaq 100, VIX และผลตอบแทนพันธบัตร 10 ปี
   - **โครงสร้างหนี้และสัดส่วนพอร์ต (15 คะแนน):** อัตราส่วนหนี้ต่อกระแสเงินสดอิสระ (Debt/FCF) และการคุมน้ำหนักกลุ่มอุตสาหกรรม
3. **การแจ้งเตือนอัตโนมัติ:** ตั้งเวลาทำงานผ่าน Windows Task Scheduler วันละ 3 เฟส (20:00 น. ช่วงวางแผน, 23:00 น. ช่วงซื้อขาย, 07:00 น. ช่วงสรุปผล)
4. **จัดการ Watchlist แยกรายบุคคล:** สมาชิกใน Discord แต่ละคนสามารถเพิ่ม ลบ และสแกนหุ้นในลิสต์ของตัวเองได้อย่างอิสระ
5. **จำกัดสิทธิ์ใช้งาน:** กำหนดให้ตอบรับคำสั่งเฉพาะในเซิร์ฟเวอร์ที่ระบุไว้เท่านั้น

## คำสั่งการใช้งานใน Discord

รองรับทั้ง Slash Command (`/`) และ Prefix (`!`):

### 1. จัดการ Watchlist
| คำสั่ง | ตัวอย่าง | คำอธิบาย |
| :--- | :--- | :--- |
| `/watchlist` | `/watchlist` | ดูรายการหุ้นในลิสต์ส่วนตัว พร้อมปุ่มกดสแกนหรือล้างลิสต์ |
| `/add` | `/add AAPL, AMD, PLTR` | เพิ่มหุ้นเข้าลิสต์ (ระบุได้หลายตัว คั่นด้วยเครื่องหมายจุลภาค) |
| `/remove` | `/remove AMZN` | ลบหุ้นออกจากลิสต์ |
| `/clear_watchlist` | `/clear_watchlist` | ล้างหุ้นทั้งหมดในลิสต์ส่วนตัว |

### 2. สแกนและดูข้อมูลราคา
| คำสั่ง | ตัวอย่าง | คำอธิบาย |
| :--- | :--- | :--- |
| `/scan` | `/scan` | สแกนหุ้นใน Watchlist พร้อมระบุสถานะ BUY / HOLD / WAIT และโซนราคาเข้าซื้อ |
| `/check` | `/check NVDA` | ตรวจสอบคะแนนอย่างละเอียด แยกตามแต่ละมิติ พร้อมกรอบราคาและจุดตัดขาดทุน |
| `/price` | `/price AAPL` | ดูราคาล่าสุด กรอบราคารายวัน รายเดือน และปริมาณซื้อขาย |
| `/history` | `/history NVDA 1mo` | ดูประวัติราคาย้อนหลัง พร้อมปุ่มสลับช่วงเวลา (5d, 1mo, 3mo, 6mo, 1y) |
| `/compare` | `/compare NVDA TSM` | เปรียบเทียบคะแนนและตัวเลขสำคัญของหุ้น 2 ตัว |
| `/macro` | `/macro` | ดูสภาวะตลาดรวม ดัชนี VIX และเกณฑ์คะแนนซื้อขั้นต่ำในปัจจุบัน |
| `/help` | `/help` | แสดงสรุปคำสั่งและวิธีการใช้งาน |

## การจำกัดสิทธิ์เซิร์ฟเวอร์ (Server Whitelist)

กำหนด ID เซิร์ฟเวอร์ที่อนุญาตให้ใช้งานในไฟล์ `discord_bot.py`:

```python
ALLOWED_GUILD_IDS = [123456789012345678]
```

หากเรียกใช้จากเซิร์ฟเวอร์อื่น บอทจะไม่ประมวลผลคำสั่ง

---

## ตารางเวลาสแกนอัตโนมัติ

ไฟล์ `setup_task.ps1` จะลงทะเบียนใน Windows Task Scheduler ตามรอบเวลา:

- **07:00 น.:** สรุปภาพรวมหลังจากตลาดสหรัฐฯ ปิดทำการ
- **23:00 น.:** ติดตามความเคลื่อนไหวช่วงเปิดตลาด

---

## วิธีติดตั้งและเริ่มใช้งาน

1. ติดตั้งแพ็กเกจที่จำเป็น (Python 3.10 ขึ้นไป):
   ```bash
   pip install -r requirements.txt
   ```
2. เริ่มการทำงานของบอท:
   - เปิดแบบแสดงหน้าต่างคอนโซล: ดับเบิลคลิก `run_bot.bat`
   - รันในเบื้องหลัง: ดับเบิลคลิก `start_bot.bat`
